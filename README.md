## 📱 دانلود نسخه‌های اندروید (Android Builds)

آخرین نسخه‌های کامپایل‌شده اپلیکیشن بر اساس معماری پردازنده گوشی شما در بخش **Releases** قابل دانلود هستند:

* 💻 **`x86_64`**: مخصوص شبیه‌سازها (Emulators) و برخی تبلت‌ها
